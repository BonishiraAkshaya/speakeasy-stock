# 📦 SpeakEasy Stock

### Voice-First Inventory Management System for Small Businesses

SpeakEasy Stock is a voice-first inventory management system designed to make stock management simple, fast, and accessible for small businesses.

Instead of depending completely on manual registers, complex inventory software, or extensive typing, users can manage their inventory using simple voice commands.

The system allows users to add products, update stock, monitor inventory levels, receive low-stock alerts, and view transaction history through a simple web interface.

---

## 🎯 Problem Statement

Many small businesses manage their inventory using notebooks, memory, spreadsheets, or messaging applications.

This can lead to:

- Manual calculation errors
- Difficulty tracking stock levels
- Missed low-stock situations
- Time-consuming stock updates
- Difficulty using complex inventory software
- Dependency on typing and technical knowledge

SpeakEasy Stock addresses these problems by providing a simple inventory management system with voice-based stock updates.

---

## 💡 Solution

SpeakEasy Stock provides a user-friendly inventory platform where users can:

- Add and manage products
- Track current stock
- Set minimum stock levels
- Update stock using voice commands
- Support multiple languages through browser speech recognition
- Automatically identify low-stock products
- View stock movement history
- Search products quickly
- Prevent stock from becoming negative

The main idea is:

> **Speak → Understand → Confirm → Update → Track**

---

# 🚀 Key Features

## 1. 🔐 User Authentication

The application provides a simple authentication flow.

Users can:

- Register an account
- Login using email and password
- Maintain their login session
- Logout securely from the application

---

## 2. 📊 Dashboard

The dashboard provides a quick overview of the inventory.

It displays:

- Total number of products
- Low-stock products
- Healthy-stock products
- Current stock overview
- Quick actions for inventory management

This allows the user to understand the overall inventory status at a glance.

---

## 3. 📦 Product Management

Users can add and manage inventory products.

Each product contains information such as:

- Product name
- Unit
- Current stock
- Minimum stock level

Example:

| Product | Current Stock | Unit | Minimum Stock |
|---------|---------------|------|---------------|
| Rice | 10 | Bags | 5 |
| Oil | 8 | Litres | 5 |
| Sugar | 3 | Kg | 5 |

---

## 4. 🎤 Voice-Based Stock Management

The main feature of SpeakEasy Stock is voice-based inventory updating.

Users can speak naturally instead of manually entering every stock transaction.

Example:

> "Rice 2 bags stock out"

The system identifies:

```text
Product  → Rice
Quantity → 2
Unit     → Bags
Action   → Stock OUT
